# Foodie-Fi Exclusive Streaming Project

## Project Overview

Foodie-Fi is a subscription-based video streaming platform that provides exclusive food content through multiple subscription plans.

The objective of this project is to analyze customer subscription behavior using SQL and answer business questions related to:

- Customer acquisition
- Subscription upgrades
- Customer churn
- Annual plan conversion
- Customer journey
- Subscription trends

This project was completed using SQL and demonstrates analytical thinking, business understanding, and advanced SQL querying techniques commonly used in Data Analyst roles.


## Analysis

- Customer Retention Analysis
- Churn Analysis
- Customer Journey Mapping
- Subscription Analytics
- KPI Reporting
- Trend Analysis
- Business Recommendation


  
## Problems 

1. Total Customers
2. Monthly Trial Distribution
3. Plans Started After 2020
4. Churn Rate
5. Churn Immediately After Trial
6. Customer Journey After Trial
7. Plan Distribution on 31-Dec-2020
8. Annual Plan Upgrades
9. Average Time to Annual Plan
10. Conversion Time Distribution
11. Downgrade Analysis
